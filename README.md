# 🦊 Me Cative

**Um vínculo não nasce pronto. Ele é construído com tempo, presença e cuidado.**

Me Cative é um jogo web educativo inspirado no universo literário de *O Pequeno Príncipe*, de Antoine de Saint-Exupéry. O projeto combina o cuidado de uma Raposa virtual com atividades educativas de vocabulário, interpretação textual e aprendizagem literária.

## 🌟 Objetivo

Proporcionar uma experiência interativa que incentive a aprendizagem, a responsabilidade, a empatia e a construção de vínculos afetivos.

## 🎮 Funcionalidades planejadas

- 🦊 **Cuidado com a Raposa:** alimentação, carinho, brincadeiras e descanso.
- ❤️ **Sistema de vínculo:** evolução da confiança por meio de interações e rituais diários.
- 📚 **Glossário das Estrelas:** minijogo de vocabulário.
- 🧠 **Escore da Sabedoria:** quiz de interpretação e compreensão textual.
- 🌌 **Coleta de Estrelas:** minijogo arcade espacial.
- ⭐ **Moeda virtual:** obtenção e utilização de Estrelas.
- 🎒 **Loja e inventário:** aquisição de alimentos, acessórios e itens de conforto.
- 🏆 **Rankings independentes:** classificação por minijogo.
- 👤 **Perfil de jogador:** progresso, conquistas e melhores pontuações.
- 🔐 **Autenticação e persistência:** contas e progresso salvos em banco de dados.
- 📱 **Design responsivo:** experiência para desktop, tablet e celular.

## 🛠️ Tecnologias planejadas

- Frontend: React + Vite
- Linguagem: TypeScript ou JavaScript
- Estilização: CSS ou Tailwind CSS
- Backend: Node.js + Express
- Banco de dados: PostgreSQL
- Hospedagem: Vercel ou Netlify para o frontend e um serviço compatível para o backend.

As tecnologias e os serviços poderão ser ajustados durante o desenvolvimento.

## 🎨 Identidade visual

Interface inspirada em livros ilustrados, céu estrelado e elementos naturais, com cores suaves e atmosfera acolhedora.

## 📈 Desenvolvimento

O projeto será desenvolvido incrementalmente, começando pelo protótipo analógico da interface e evoluindo para as mecânicas de jogo, persistência de dados e rankings.

## 🎯 Público-alvo

Pessoas interessadas em jogos educativos, literatura, vocabulário, interpretação textual e experiências interativas acolhedoras.

**Me Cative — pequenas interações, grandes vínculos.** 🦊✨
